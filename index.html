PRÁCTICA N°5 - JavaScript

1. Formas de conectar HTML con JavaScript

Existen dos formas principales de conectar JavaScript con HTML:

a) JavaScript interno

Consiste en escribir el código JavaScript dentro del mismo archivo HTML utilizando la etiqueta <script>.

Ejemplo:

        <script>
        alert("Hola Mundo");
        </script>

b) JavaScript externo

Consiste en crear un archivo separado con extensión .js y enlazarlo al HTML mediante la etiqueta <script>.

Ejemplo:

        <script src="script.js"></script>

Esta forma es la más recomendada porque permite organizar mejor el código.

2. Cómo visualizar resultados en la consola del navegador

  1. Abrir el navegador web.
  2. Abrir el archivo HTML.
  3. Presionar F12 o clic derecho -> Inspeccionar.
  4. Seleccionar la pestaña "Consola".
  5. Utilizar console.log() en JavaScript.

Ejemplo:

        console.log("Hola desde JavaScript");

El mensaje aparecerá en la consola del navegador.

3. Variables en JavaScript

Las variables son espacios en memoria que sirven para almacenar datos.

a) var

        var nombre = "Juan";
        console.log(nombre);

var ya no se recomienda porque puede causar errores debido a su alcance.

b) let

        let edad = 20;
        console.log(edad);

let permite modificar el valor de la variable.

c) const

        const PI = 3.1416;
        console.log(PI);

const se utiliza para valores que no cambiarán.

Actualmente se recomienda utilizar let y const.
